# 20 Python Beginner Projects

This repository contains 20 beginner-friendly Python projects I built to learn core concepts like data types, loops, functions, OOP, file handling, APIs, `pandas`, `turtle`, and `tkinter`.

Each project lives in its own folder with:

- `main.py` – main source code
- `README.md` – short description, concepts learned, and how to run it

---

## 🔧 Tech Stack

- Python 3.x
- Modules used across projects:
  - `turtle`
  - `tkinter`
  - `pandas`
  - `requests`
  - `smtplib` / notification libraries (for alerts)
  - standard library modules (`random`, `time`, `os`, etc.)
